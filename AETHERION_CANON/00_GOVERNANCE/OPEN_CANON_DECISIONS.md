## Resolution record template

Decision ID; version; old specification; proposed replacement; evidence IDs; rationale; alternatives; affected IDs; gameplay and asset impact; save migration impact; rollback plan; reviewer; founder approval message/location; approval date; validation report; status transition. Never replace an UNRESOLVED field with an invented value simply to satisfy a schema: schemas must allow explicit unknown values with a reason.
