# Production roadmap: from evidence to a playable covenant

Status: PROPOSED. These are dependency-ordered work packages, not promised delivery dates, staffing commitments or completed assets. The next milestone is a **bounded cross-Oath vertical slice**, not simultaneous production of an entire continent.

## Scoring convention

Evaluate each backlog item on dependency importance, gameplay significance, narrative significance, cross-system reuse, production complexity, visual differentiation and technical risk. Scores are ordinal 1–5 design assessments, not measured ROI. Priority favors blockers/reuse/risk reduction before sheer quantity. Complexity informs sequencing rather than pretending complex work is less valuable. Actual estimates require asset review and profiling.

## Gate 0 — evidence and import acceptance

- Freeze source SHA and a byte-preservation manifest; reconcile all source castables against the destination, including buffs and summons, not only the default native ability list.
- Keep imported code behavior intact. Separate original executable contracts from proposed character/combat/network/game-world services.
- Recover and preserve original reference bytes with a traceable identity. Record collisions, correction candidates and individual approval uncertainty.
- Execute available module, source-fixture, simulation, adapter and asset-resolution tests. A failed GPU capability test is a blocked gate, not a successful effect-rendering test.
- Approval: founder reviews locked/proposed boundaries, source gaps and migration report. A draft PR is a review artifact, not a merge instruction.

Exit evidence: no invented source count; no accidental duplicates; documented executable coverage and unresolved cases; resolvable required data links; honest image/production status.

## Gate 1 — approve a small art and interaction benchmark

Choose the proposed Daybreak opening plaza and one adjacent boundary corridor only after world-layout approval. The benchmark should include two distinguishable Oath silhouettes, civilian work, a reversible environmental interaction and a meaningful covenant choice. The selection must not demote other Oaths or lock the player's first allegiance.

- Approve the relevant reference sheets individually and produce model construction/rig/material tests.
- Choose target devices and a full-game engine/network prototype. Existing Three.js sandbox fidelity is preserved regardless of the future engine decision.
- Measure one real character, equipment family and representative VFX load on each nominated tier. Set budgets from results, not aspiration.
- Implement the proposed interaction authority in isolation with deterministic event IDs, bounds, rollback/recovery and accessible cues.

Exit evidence: approved art benchmark; measured device results; no irreversible terrain grief; source behavior parity for selected castables; clear fallbacks for unsupported targets.

## Gate 2 — first playable covenant loop

A short loop must connect the Archivist's death, a civic obligation, travel, a combat/noncombat solution, and a consequence visible in the local world. Use one authored region segment and two covenant perspectives; the fragment enables exceptional multi-binding without making every unpledged citizen equivalent to the Archivist.

Required loop: read a pact → choose initiation route → equip a finite active loadout → perform one civic/craft and one encounter objective → receive a legible local consequence → reconcile or accept it → return safely. Test refusal, failure, disconnect and accessibility paths, not just the optimal combat build.

Exit evidence: founder narrative/art review; independent playtest; complete save migration/restore tests; no unwarned permanent losses; playable alternate first-Oath routes documented.

## Gate 3 — systemic robustness before breadth

Expand to three interacting regions only when the vertical slice supports repeated sessions. Test directional elemental states, weather migration, caravan interruption/recovery, civilian schedules, housing ownership and consent-scoped conflict. Simulate resource scarcity without rewarding grief or permanent monopolies. Validate cross-region input/asset streaming budgets.

Exit evidence: deterministic replay checks; multiplayer authority/latency/cheat tests if networking is selected; bounded damage/reconstruction; no one Oath supplies every strategic input; mandatory narrative access survives territory turnover.

## Gate 4 — realm-by-realm production

Produce the fifteen realms in dependency batches using the common dossier and coverage criteria. Each realm needs playable civilian/economic identity, recognizable silhouettes without VFX, narrative alternatives, creature ecology and transition assets. No realm is accepted because its headings are filled or its concept sheet exists.

Exit evidence for each realm: approved representative assets, actual implemented interactions, performance/rig/collision/LOD checks, accessible encounter readability, quest/branch continuity and a validated neighboring transition.

## Gate 5 — regional conflict and endgame consequences

Sieges, world bosses and ending transitions are late integration gates, not early promises. Territory changes modify bounded states, services and authored scenes; they do not permanently remove dungeons, housing or new-player access. Test all three thematic ending directions for coherent advantages/costs and rollback of technical failure, while preserving explicitly irreversible narrative choices.

Exit evidence: full branch audit, load/authority tests, anti-grief exploits closed, reconstruction lifecycle proven, localization and accessibility review, commercial-rights clearance.

## Change-control rule

Adding another ability or art family cannot displace source parity, consent/recovery, data integrity or visual differentiation gates. New ambitions become backlog entries with dependencies and approval, not silently declared implemented systems. The complete foundational package is useful now; final world/game production remains dependent on the evidence above.
