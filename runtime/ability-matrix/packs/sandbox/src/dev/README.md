# Experimental expansion test harness

Run the sandbox with Vite and open `/?expansionDev=1`. Expand **Experimental cast tests**, choose a candidate and press **Cast**. The matching folder is added to the VFX editor. The cast originates at the player. Set heading in degrees (0 is positive Z; 90 is positive X) and distance in metres; the harness clamps distance to the ability range. Self-targeting abilities cast at the player.

This is an opt-in developer tool. Candidates do not appear in the public matrix or its native catalog. They are unfinished: an ability accepting a cast is not evidence of visual parity, complete mechanics or suitability for release. Combat interactions use the sandbox combat adapter when enabled; unsupported adapter capabilities remain unsupported.
