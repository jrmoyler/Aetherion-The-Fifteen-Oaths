# Impulse shield dimensional reading — review addendum

Published baseline: `5a30e8d0fd3caa2ed9fbf82d6c7fe532a2d01b12`.

Direct pixel inspection of `assets/references/reference-032/original.png` shows a vertical dimension arrow labeled **95 cm** beside the unfolded shield and a horizontal dimension arrow labeled **25 cm** above the stowed shield. The supported reading is unfolded height 95 cm and stowed width 25 cm. The image does not explicitly establish stowed height as 25 cm.

Earlier candidate manifest/review language treated 25 cm as folded length. That interpretation is not supported by the arrow direction and must not be used as evidence that the source requires longitudinal telescoping. Historical review records are retained; this addendum corrects the dimensional interpretation.

The parent has separately requested a longitudinal telescoping repair. A 25 cm-high telescoping mechanism would therefore be an additional proposed engineering design, pending clarification, rather than a faithful reconstruction of a source-specified length. Any such prototype must distinguish measured width, height and thickness throughout the motion, keep rigid panels rigid, and report clearance/intersection limits. Existing production GLBs remain unchanged.
