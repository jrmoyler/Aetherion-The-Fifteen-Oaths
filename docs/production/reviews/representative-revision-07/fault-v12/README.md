# Fault blade V12 — focused, unapproved geometry diagnostic

Original reference053 is the target. V11 remains frozen and unchanged. This isolated candidate is not a production promotion or exact-art approval; no repository assets, source Ability Matrix or reference-upload files were changed.

## Geometry changes

The opening between the stone banks uses explicit unequal-width stations, restoring broader purple exposure than V11's narrow zigzag crack. Stone plates have unequal depth stations, oblique individual slopes and asymmetric front/back layers; the edge-on profile no longer presents only parallel rails. Crystal depth follows the stone envelope. The prior brown leather, compact overall guard/pommel proportions and source-traced long leaf outline remain.

The final few millimeters of mineral layers converge into one cutting plane, correcting the split tip seen in the first diagnostic. A 10-micrometer vertex weld and degenerate-edge cleanup remove coincident/sliver geometry generated by the taper. Several intermediate builds exposed zero tangent loops on long, micrometer-thin tip faces; their diagnostic logs are preserved. Final topology/UV calculation asserts valid tangents, and the exported GLB retains all tangent attributes. No tangent omission or fake optical emission was used.

## Evidence

Two final Cycles CPU renders at 256 samples use the unchanged neutral lights and source-oriented approximate camera roll. They are not a calibrated source-camera match. `diagnostic-first-pass` preserves the earlier profile; intermediate failed-build logs are superseded, not final evidence.

The final source contains 147 mesh objects with actual UVs and materials, and 16 packed/external 512px PBR maps. Actual Blender GLB reimport: 147 mesh objects and 11,372 triangles. Proposed dimensions are 0.118945 × 0.080125 × 0.773522 m in Blender XYZ; these are authored proposal measurements, not new canon dimensions. UV audit finds 0 collapsed nonzero-area UV triangles and 0 geometry triangles below 1e-12 m².

Final Khronos validation: 0 errors, 0 warnings, 6 informational unused tangents on optical materials without normal textures. Blender reimport, source inspection and source-byte-unchanged export receipts are supplied. Independent imports are recorded separately by the reviewer. None establish engine-rendered optics, GPU performance or gameplay acceptance.

## Remaining visible gaps

The crystal still reads as a relatively straight, flat purple strip. Reference053 has chunkier unequal facets, brighter angular depth and a larger irregular opening near the collar. Stone plates remain too uniformly arranged and broad compared with varied overlapping mineral terraces. The guard reads as a cylindrical cuff and the pommel as a simplified prism, with less irregular ornament than the reference. These remain failed visual gates; no full render set is justified yet.

A next geometry pass should prioritize actual crystal facet depth and unequal width, natural mineral lips/terraces and compact irregular guard construction, not color-only changes. LOD/collision packages, grip/stow fit, engine-rendered transmission, GPU performance and gameplay remain open. Static equipment does not need a deformation rig.

## Reproduction

Use Blender 4.3.2 from this folder:

```
blender -b -t 2 --python fault_weapons.review.py
blender -b -t 2 --python render_matched.py
blender -b -t 2 --python export_review_glb.py
blender -b -t 2 --python inspect_source.py
blender -b -t 2 --python audit_uv.py
node validate_glb.cjs
blender -b -t 2 --python import_review_glb.py
```

`AETHERION_REVIEW_OUT` can choose another output directory; `GLTF_VALIDATOR_MODULE` can select an installed validator module. The standalone author recipe is final; the initial revision helper under diagnostics is history only. Final files and hashes are in `REVIEW_EVIDENCE.json` and `SHA256SUMS`.
