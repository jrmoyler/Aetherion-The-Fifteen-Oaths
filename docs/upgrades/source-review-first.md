## Integration guardrails

Prefer the existing Aetherion runtime and its canonical Ability-Matrix assets. Choose isolated, measured improvements over replacing the engine. Record exact commit, original path, local path, modifications and license for each actual import. Do not describe this review as imported code. Do not use unlicensed, noncommercial or no-redistribution sources as vendored dependencies. Asset galleries and example repositories do not confer a blanket license over all linked artwork.
